# PokéAPP - Pokédex y Comparador (Ionic Angular)

Aplicación móvil interactiva desarrollada con **Ionic Framework** y **Angular (Standalone Components)** que consume la **PokéAPI REST v2** para búsqueda, visualización multimedia (galería de más de 5 imágenes, sonidos oficiales, animaciones GIF) y comparación y simulación de combate entre personajes.
