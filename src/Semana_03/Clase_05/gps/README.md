# Geolocalización y Rutas GPS (Ionic Angular)

Aplicación móvil minimalista desarrollada con **Ionic Framework** y **Angular (Standalone Components)** para captura de posición GPS, cálculo de rutas con waypoints hacia sitios de interés y exportación de reportes en `.txt`.
