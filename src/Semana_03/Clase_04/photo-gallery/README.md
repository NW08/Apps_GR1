# Galería de Fotos (Photo Gallery)

Aplicación móvil desarrollada con **Ionic**, **Angular (Standalone Components)** y **Capacitor**.

Permite capturar imágenes con la cámara del dispositivo o webcam, almacenarlas persistentemente en el sistema de archivos local (`@capacitor/filesystem`), visualizarlas en una cuadrícula dentro de la galería y eliminarlas interactivamente tanto de la vista como del almacenamiento físico.
