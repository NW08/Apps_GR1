# Desarrollo de Aplicaciones Móviles — GR1

Repositorio de prácticas y proyectos desarrollados para la materia de **Desarrollo de Aplicaciones Móviles GR1** de la **Escuela Politécnica Nacional**.

Cada carpeta corresponde a un proyecto independiente con su propio `README.md` donde se detalla su propósito, arquitectura y guía de ejecución.

Todos los proyectos se construyen sobre **Ionic + Angular + Capacitor**; la columna _Novedad_ solo indica lo que cada proyecto introduce.
