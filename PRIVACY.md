# Política de Privacidad — PokéAPP

**Última actualización:** 16 de noviembre de 2026

**PokéAPP** (`ec.edu.epn.pokeapp`) es una aplicación móvil académica desarrollada con Ionic, Angular y Capacitor.

## 1. Recopilación de datos
PokéAPP **no recopila, almacena ni comparte datos personales** de los usuarios (como nombre, correo electrónico, ubicación, contactos o identificadores del dispositivo).

## 2. Servicios de terceros
La aplicación realiza únicamente consultas de lectura a la API pública **PokéAPI** (`https://pokeapi.co/api/v2`) para mostrar información, imágenes y sonidos de Pokémon. No se envían datos personales en dichas solicitudes.

## 3. Publicidad y compras
La aplicación no contiene anuncios ni compras dentro de la aplicación.
